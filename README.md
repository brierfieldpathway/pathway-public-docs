# Brierfield Pathway public documentation

Permanent repository for the public-facing documentation site, built using Astro Starlight and GitHub Pages.

Preview: https://brierfieldpathway.github.io/pathway-public-docs/

Initially, only public links, navigation and non-sensitive descriptive text are published. No document is considered approved merely because a link exists.

Development requires Node.js 24. Run npm ci, then npm run build. Pull requests build but do not deploy.

Tracking: private coordinator issue #11 (hosting) and #17 (reader experience).

No custom domain, live site, DNS or CT206 settings are changed.
