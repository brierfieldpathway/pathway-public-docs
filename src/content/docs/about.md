This public website is maintained in the [Brierfield Pathway public documentation repository](https://github.com/brierfieldpathway/pathway-public-docs).

- GitHub Pages serves approved static files independently of the local Proxmox servers.
- CT206 remains the coordinator for scanning and reviews. It does not serve the published website.
- Private documentation requires separate authenticated hosting.
- Future controlled documents must pass the release/approval process; no automatic publishing is active.

For website corrections, open a [public issue](https://github.com/brierfieldpathway/pathway-public-docs/issues) without including confidential details.
